Layout contract

Keep the resizable builder available while switching canvas tabs. Row expansion changes every comparison column together. The selected row controls the chart; chart legend emphasis is independent of table columns. Pin identifiers while horizontally scrolling wide factor tables.

What changes, what stays

Historical / Forward-looking changes the analytical basis. Contributions / Differences changes the displayed values. Reference mode changes the comparator, explicitly named in each column. Factor selections apply to all allocations. These controls preserve row expansion and editing context.

Acceptance checks for this example
  • Editing 55% to 50% leaves 5% unallocated; other sleeve weights are not normalized.
  • With leverage disabled, negative inputs or a total above 100% are flagged; with it enabled, signed weights are accepted without risk limits.
  • Risk shares total 100% for a non-zero modeled risk portfolio; volatility contributions sum to modeled portfolio volatility. A zero-risk portfolio shows an unavailable share.
  • Expanding Growth reveals children; their weights sum to Growth. The demo preserves child proportions when a parent changes; this is a proposed rule.
  • Snapshot columns remain fixed after subsequent edits. Selecting a snapshot disables builder editing until a live allocation is selected.

Example defaults Positive unallocated weight earns zero in this toy model; negative residual is shown as illustrative borrowing, not a priced financing leg. Production cash, financing, derivative exposure and child-weight rules remain explicit open decisions.
